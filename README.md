# Power-Transformer-Design
AutoCAD drawing of transformer assembly and components

# Overview
This repository contains an AutoCAD drawing of a transformer, created as part of my work in electrical engineering. The drawing illustrates the key constructional details of the transformer, including core, windings, tank, and assembly layout.

# Files Included
Transformer.dwg → Original AutoCAD drawing (editable in AutoCAD).
Transfromer Drawing Images.zip → Preview image of the drawing. (zip file).

# Features
Detailed transformer assembly layout.
Accurate dimensions and proportions.
Layered drawing for easy editing (core, winding, tank).
Prepared using AutoCAD 2021.

# How to Use
Download the repository or clone it: git clone https://github.com/username/Transformer-Design-AutoCAD.git
Open Transformer.dwg in AutoCAD.
If you don’t have AutoCAD, view Transfromer Drawing Images.zip
